# 入出力サンプル

## サンプル入力

```text
（Deep Researchの出力を丸ごと貼るか、ファイルを指定して）

この調査結果を deep-research-report でレポートにして。宛先は経営会議。
```

入力の実物例: [assets/sample-research.md](../assets/sample-research.md)
（結論が最後・数字が文中に埋没・出典が羅列された、よくある調査出力）

## サンプル出力

出力の実物例: [assets/sample-report.html](../assets/sample-report.html)（ブラウザで開けます）

変換で起きること（上の実物ペアで確認できます）:

- 第5章にあった示唆と第1章の数字が、冒頭のエグゼクティブサマリー3点に再配置される
- 文中の「18%→29%→41%→54%→68%」が折れ線チャートに、部門別の羅列が横棒チャートになる
- 「ステージ0〜3」の文章説明が、矢羽根見出しつきのステージ表になる
- 出典[1]〜[10]は消えず、巻末の出典一覧に整理される
- 原文の「85%超」は「85%超」のまま使われる（87%などに盛られない）。予測は破線で描かれる
