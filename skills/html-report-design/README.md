# HTML資料デザイン（html-report-design）

**「HTMLで出して」と指示した瞬間にだけ働き、Claudeが書き出すHTMLを野暮ったい既定デザインからコンサル品質の資料デザインに整えて出力するスキル。**

ClaudeやChatGPTにHTMLで資料を作らせると、枠線だらけのカードUI・紫のグラデ・絵文字見出しの
「AIっぽい画面」が返ってくる。このスキルを入れると、余白と文字階層で構造を作る
報告書スタイルに矯正され、社内外に配布できる見た目で出力される。

## 仕組み（いつ働くか）

- 普段の会話・分析・コーディングでは何もしない。**HTMLを出力する瞬間にだけ**適用される
- 適用されると、既定のAIっぽいデザイン（枠だらけのカード・グラデ・絵文字・虹色）を封じ、
  余白と文字階層で組んだ配布資料デザインで書き出す
- ユーザー側の操作は不要。「HTMLで資料にして」と言うだけで自動発火する

## なぜAIのHTMLはダサいのか

原因は1つ。**構造を「線と箱」で作っているから。**
一流の資料は構造を「余白と文字の階層」で作る。このスキルはそこを強制的に入れ替える。

| デフォルトのAI出力 | このスキルの出力 |
| --- | --- |
| セクションごとに角丸カード＋影 | 余白64px＋横の細罫1本で区切る |
| 紫→青のグラデーション背景 | 白紙面＋濃紺のアクセント1色（面積5%以下） |
| 絵文字つき見出し（🚀 ポイント） | 番号＋見出し＋メッセージライン（so what） |
| 青・黄・緑の色付き情報ボックス | グレーの注記と出所表記 |
| 全セル罫線のExcel風テーブル | 縦罫なし・横細罫のみ、数字は右揃え・単位明記 |
| 虹色に塗り分けたグラフ | 脇役はグレー、主役1系列だけ濃紺 |
| 箱と矢印の自由描画な「図解」 | 矢羽根・ロードマップ・バブルマップ・ウォーターフォールの型 |
| 画面で映えるダークUI | A4印刷で崩れない配布資料 |

## 出力されるもの

- 表紙ブロック（取扱い表記・タイトル・リード・日付/部署/宛先）
- エグゼクティブサマリー（結論→根拠→依頼の3点）
- 番号付きセクション（見出し＋メッセージライン＋根拠となる表・KPI・図）
- コンサル図解の型: 矢羽根（フロー/バリューチェーン）・ロードマップ・
  フレームワーク表（左に濃色ラベル＋等間隔の列。論点一覧・ステージ比較）・
  バブルマップ・ウォーターフォール・折れ線・横棒（すべてHTML/CSS/SVGで完結、画像なし）
- 推奨アクション（誰が・何を・いつまでに）
- A4印刷対応のCSS一式（変えるのはアクセント1色だけ）

完成見本: [assets/report.template.html](./assets/report.template.html) をブラウザで開くとそのまま確認できます。

## 導入

### いちばん簡単: Claudeに貼るだけ（デスクトップアプリOK）

Claude Code（デスクトップ版・CLIどちらでも）に、次の1行を貼るだけです。

```text
https://github.com/Ted0321/kotetsu-work-ai-skills の skills/html-report-design を ~/.claude/skills/ にインストールして
```

Claudeがリポジトリを取得してスキルを配置します。以後は「この分析、HTMLで資料にして」と
言うだけで自動発火します。既存のダサいHTMLを渡して「このスキルで直して」でも使えます。

### コマンド派（Claude Code / Cursor / Codex）

```bash
npx skills add Ted0321/kotetsu-work-ai-skills@html-report-design
```

### コピペ型（Claude / ChatGPT / Gemini など何でも）

1. [SKILL.md](./SKILL.md) を開いて中身をAIに貼る
2. 末尾に案件メモ（資料にしたい内容）を足す

X等でのシェア・お試し用には約4,500字の凝縮版
[assets/prompt-lite.md](./assets/prompt-lite.md) もあります
（表・KPI・矢羽根・フレームワーク表まで再現。ロードマップやSVGチャートの実装見本はフル版のみ）。

想定セッション例: [examples/sample_input_output.md](./examples/sample_input_output.md)

## 注意

- 既定のアクセントは濃紺（`#173f66`）。会社・クライアントのコーポレートカラーがある場合は
  「アクセントは #xxxxxx で」と一言添えれば、その1色だけ差し替わります
- 白背景・印刷前提のデザインです。ダークテーマのダッシュボードが欲しい場合には向きません
- デザイン（見た目）のスキルです。中身（論点・結論）の質は内容系のスキルや
  レビューと併用して担保してください
