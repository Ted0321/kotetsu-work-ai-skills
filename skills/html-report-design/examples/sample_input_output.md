# 入出力サンプル

## サンプル入力

```text
（SKILL.md の本文を貼った上で）

# 案件メモ
競合3社の調査結果がまとまったので、経営会議向けにHTMLで1枚の報告資料にして。
要点: 市場は伸びてる（年12%）、化粧品領域だけ競合が薄い、参入するなら人の採用がボトルネック。
最後に「条件付きで参入承認をもらう」流れにしたい。
```

### ここがデフォルト出力と違う

- セクションをカード（枠＋角丸＋影）で囲まず、余白と細罫1本で区切っている
- 色は黒グレー系＋濃紺の1色だけ。絵文字・グラデ・色付きボックスがない
- 各セクションの先頭に「言いたいこと1文」（`.msg`）があり、飛ばし読みできる
- 図解は型で出る: 矢羽根（バリューチェーン）・バブルマップ（ポジショニング）・
  ウォーターフォール（投資回収）・フレームワーク表（ステージ比較・リスク一覧）・
  ロードマップ（スケジュール）がHTML/SVGで完結
- 数字は右揃え・単位明記・出所つき。A4印刷してそのまま配れる
