# 入出力サンプル

## サンプル入力

```text
古くなった Claude Code のキャッシュ・セッションログ・一時ファイルを安全に掃除する週次自動化をセットアップして。
アクティブなものや最近のものには触らず、置きっぱなしで容量を食っている古いデータだけを対象に。
毎回私に聞かずに、毎週自動で実行して。
```

## サンプル出力（理想イメージ・macOSの例）

```markdown
まず現状をドライランで確認しました（何も削除していません）：

| 場所 | 対象 | サイズ |
|---|---|---|
| ~/.claude/projects/（古いセッションログ） | 214件 | 約380MB |
| ~/.claude/shell-snapshots/ | 96件 | 約1.2GB |
| ~/.claude/file-history/ | 310件 | 約95MB |
| ~/Library/Caches/claude-cli-nodejs/（MCPログ） | 58件 | 約210MB |
| $TMPDIR/claude-*（一時ファイル） | 12件 | 約40MB |
| 合計 | 690件 | **約1.9GB** |

（この後、保持日数と実行タイミングを1回だけ確認 → 設置・登録・初回実行）

━━━ Claude Code おそうじレポート ━━━
 before : 2.1 GB（1,240 ファイル）
 after  : 0.2 GB → ★1.9 GB 回収★
 内訳   : 会話ログ 0.4 GB / スナップショット 1.2 GB / MCPログ 0.2 GB / その他 0.1 GB
 次回   : 毎週月曜 9:00 に自動実行（もう確認しません）
 停止   : 「おそうじ自動化を止めて」と言えば解除
━━━━━━━━━━━━━━━━━━━━━━
```

## 設定後の使い方

```text
掃除の結果見せて          → 直近の実行ログを要約
今すぐ掃除して            → その場で1回実行
おそうじ自動化を止めて    → スケジューラ登録を解除
```
