# X投稿ネタ帳: ビジネスマン向けAI小技・裏技バックログ

薄配布（X直接投稿）用のネタ帳。投稿時は [templates/thin_drop_x_post.md](../templates/thin_drop_x_post.md) の型に流し込む。

## これまでのヒットの法則

過去にウケた4本（Claude Code→GPT画像生成 / セッション名自動リネーム / Codexでコンサル資料 / サブエージェント可視化）の共通項:

| 法則 | 中身 | 例 |
|---|---|---|
| **A. 越境** | AツールからBツールを使う意外性 | Claude Code→GPT画像 |
| **B. 面倒の自動化** | 毎日の小さいストレスをhookや設定で消す | セッション自動リネーム |
| **C. 映える成果物** | ビフォーアフターのスクショが作れる | コンサル風資料 |
| **D. 可視化** | 見えないものがスクショ1枚で見える | サブエージェントの動き |

横断条件: **5分で真似できる / スクショ映えする / 「それ知らなかった」感がある**。

## ネタ一覧（15本）

対象の凡例: `コピペ勢` = ChatGPT/Claude/Geminiだけの人でも可 / `CLI勢` = Claude Code・Codexユーザー向け

### 法則A: 越境（〇〇から△△を使う）

#### 1. Claude Codeの中からGeminiに「セカンドオピニオン」を聞かせる
- **何ができる**: 設計判断や文章レビューのとき、Claude Codeが自分でGemini CLIを呼んで他社AIの意見を取りに行く。1つの画面で2社のAIが議論する。
- **やり方**: Gemini CLIを入れておき、CLAUDE.mdに「重要な判断の前に `gemini -p "<相談内容>"` で第三者意見を取得し、相違点を報告せよ」と書くだけ。
- **ウケる理由**: 「Claude Code→GPT画像」と同型の越境ネタ。モデルの相性論争が盛んなので引用が伸びやすい。
- **対象**: CLI勢
- **検証メモ**: Gemini CLIの無料枠と最新の呼び出しオプションを確認。Codex CLI（`codex exec`）を呼ぶ3社会議バージョンも試す。

#### 2. Claude Code×Playwright MCPで「毎朝のブラウザ巡回」を任せる
- **何ができる**: 競合サイト・ニュース・管理画面など毎朝見る定型ページを、AIがブラウザを実際に開いて巡回し、変化点だけ報告する。
- **やり方**: `claude mcp add playwright -- npx @playwright/mcp@latest` を追加し、「この3つのURLを開いて昨日との差分を要約して」と指示。巡回手順はスキル化すると再利用できる。
- **ウケる理由**: AIがブラウザを操作する画面自体がスクショ映えする（法則Dも兼ねる）。
- **対象**: CLI勢
- **検証メモ**: ログインが必要なサイトの扱いと、社内規程に触れないサンプル題材を用意。

#### 3. 1コマンドでMarkdown→スライドPDF（Marp）
- **何ができる**: AIに書かせたMarkdownを `npx @marp-team/marp-cli slide.md -o slide.pdf` でそのままスライドにする。パワポを一度も開かずに提案骨子が完成。
- **やり方**: 「Marp形式で、1スライド1メッセージ、10枚で提案骨子を書いて」→ 出力をmarp-cliでPDF化。CSSテーマを1つ作っておくと毎回同じ見た目になる。
- **ウケる理由**: 「Codexでコンサル資料」の続編として出せる。ビフォー（Markdown）→アフター（スライド）の並びが映える。
- **対象**: CLI勢（Node入りなら実質コピペ）
- **検証メモ**: 日本語フォントの崩れ、pptx出力（編集可能版は実験的機能）の現状を確認。

#### 4. 会議の録音を投げるだけで「決定・宿題・期限」の3点議事録
- **何ができる**: スマホ録音ファイルをAIに渡し、要約ではなく「決まったこと / 誰がいつまでに何をやるか / 決まらなかった論点」の3表で出す。
- **やり方**: 音声対応AI（Gemini等）に録音を渡し、3表フォーマットのプロンプトを固定で使う。Claude Codeなら文字起こし→整形→Slack下書きまで一気通貫にできる。
- **ウケる理由**: 需要が最大級。「要約」ではなく「宿題表」という切り口が論点整理スキルとも接続する。
- **対象**: コピペ勢
- **検証メモ**: 60分級の長尺での精度、話者分離の限界を実測してから出す。録音は社内同意が前提と一言添える。

#### 5. GAS×AIで「スプレッドシート業務」を自動化（コードはAIが書く）
- **何ができる**: 毎週のレポート集計、フォーム回答の自動転記、期限リマインドメールなどを、プログラミング知識ゼロでGoogle Apps Script化する。
- **やり方**: AIに業務を説明→GASコードを出させる→スプレッドシートの拡張機能→Apps Scriptに貼る→トリガー設定。エラーはスクショごとAIに投げ返す。
- **ウケる理由**: 「自分はコードを書かない、貼るだけ」という再定義が刺さる。非エンジニアのビジネスマンに最も届く自動化。
- **対象**: コピペ勢
- **検証メモ**: 題材は「フォーム回答→自動お礼メール」など汎用で承認権限が要らないものにする。

### 法則B: 面倒の自動化

#### 6. AIの作業完了をスマホに通知させる（席を立ってよくなる）
- **何ができる**: Claude Codeの長い処理が終わった瞬間、スマホに通知が届く。画面の前で待つ時間がゼロになる。
- **やり方**: 無料のntfy.shを使い、Stopフックに `curl -d "作業完了" ntfy.sh/自分のトピック名` を仕込む。スマホにntfyアプリを入れるだけ。アカウント登録不要。
- **ウケる理由**: 「セッション自動リネーム」と同じhook系QoLネタ。「AIを待つ時間」は全ユーザー共通の不満。
- **対象**: CLI勢
- **検証メモ**: Windows/Macそれぞれでフック設定JSONを動作確認してからスクショを撮る。トピック名は推測されない文字列にする注意書きを入れる。

#### 7. 毎朝、出社前にAIが「今日のブリーフィング」を作っておく
- **何ができる**: 起きたら、担当業界ニュースの要約・今日の予定の論点・返信すべきメールの下書きができている。
- **やり方**: `claude -p "指示"` をWindowsタスクスケジューラ（Macならcron）で毎朝実行し、結果をMarkdownやメールに出す。ChatGPTのタスク機能でも簡易版が可能。
- **ウケる理由**: 「寝ている間にAIが働く」は普遍的に強いフック。定型プロンプトを配布物にできる。
- **対象**: CLI勢（ChatGPT版はコピペ勢）
- **検証メモ**: ヘッドレス実行時の権限設定（`--allowedTools`等）と、Web版Claude CodeのRoutines/スケジュール実行の最新仕様を確認。

#### 8. AIに仕事を任せる前に「安全柵」を置く（危険コマンドのブロック）
- **何ができる**: ファイル削除・強制pushなどの危険操作を、実行前にフックで自動ブロック。「AIに消された」事故を仕組みで防ぐ。
- **やり方**: PreToolUseフックで `rm -rf` 等のパターンを検知したら拒否を返す。permissionsのdenyリストでも大半は足りる。
- **ウケる理由**: 自動化ネタが流行るほど事故の不安も増える。攻め技の後に守り技を出すと信頼が乗る。
- **対象**: CLI勢
- **検証メモ**: フックとpermissions設定のどちらを主役にするか、最新の設定スキーマで動作確認。

### 法則C: 映える成果物

#### 9. 報告書をパワポでなく「HTMLダッシュボード1枚」で出す
- **何ができる**: 週次報告や調査結果を、グラフ・表・進捗バー入りの自己完結HTML1ファイルにする。開くだけで見られて、更新はAIに「数字差し替えて」と言うだけ。
- **やり方**: 「この報告内容を、外部ライブラリなしの単一HTMLダッシュボードにして。KPIカード3枚＋グラフ＋所感の構成」で生成。以後は同じファイルを更新させる。
- **ウケる理由**: ビフォー（箇条書きメモ）→アフター（ダッシュボード）のスクショ落差が最大級。
- **対象**: コピペ勢（Claude/ChatGPTのプレビュー機能でも可）
- **検証メモ**: 社外共有時の取り扱い（ファイル添付かURLか）の推奨をひとこと入れる。

#### 10. 領収書の写真を投げるだけで経費精算Excelができる
- **何ができる**: 出張後の領収書の山をスマホで撮影→フォルダに入れてAIに渡すと、日付・金額・店名・費目を読み取ってExcel一覧にする。
- **やり方**: Claude Codeで「このフォルダの画像から経費一覧のxlsxを作って。合計行と費目別集計も」と指示。コピペ勢は画像を直接チャットに貼ってCSVで受け取る。
- **ウケる理由**: 全ビジネスマン共通の苦役。月末に投稿すると刺さる。
- **対象**: 両方
- **検証メモ**: 手書き・かすれ領収書の読み取り精度を実測。金額は必ず目視確認、経費データの扱いは社内規程に従う旨を明記。

#### 11. AIに図を「コード（Mermaid）」で描かせると、あとから直せる
- **何ができる**: 体制図・業務フロー・ガントチャートをMermaid記法で生成させ、draw.ioやNotionに貼って編集可能な図として使う。画像生成と違い、修正が一瞬。
- **やり方**: 「この体制をMermaidで」→ 出力をdraw.io（配置→挿入→高度な設定→Mermaid）やmermaid.liveに貼る。ガントは `gantt` 記法で締切管理まで。
- **ウケる理由**: 「AIの図解は直せないから使えない」という通説への反論ネタ。図解系は保存されやすい。
- **対象**: コピペ勢
- **検証メモ**: draw.ioのMermaid取り込みメニューの現行UIを確認。日本語ラベルの折返し崩れに注意。

#### 12. 資料フォルダを「耳で読む」（NotebookLMの音声解説）
- **何ができる**: 30ページの資料や積読PDFをNotebookLMに入れ、対話形式の音声解説にして通勤中に聴く。
- **やり方**: NotebookLMにPDFを追加→音声概要を生成。「明日の会議の想定問答を中心に」など焦点の指定もできる。
- **ウケる理由**: 定番だが数字が取れ続けている鉄板。読む時間がないという普遍的な悩みに効く。
- **対象**: コピペ勢
- **検証メモ**: 日本語音声の現在の品質と生成時間、動画解説機能の対応状況を確認してから書く。

### 法則D: 可視化

#### 13. AIにいくら使ったか、1コマンドで見える化（ccusage）
- **何ができる**: `npx ccusage@latest` で、Claude Codeのトークン使用量と概算コストが日別・モデル別に表で出る。「今月使いすぎ?」が3秒でわかる。
- **やり方**: ローカルに残る会話ログを集計するOSS。インストール不要でnpx一発。
- **ウケる理由**: 「サブエージェント可視化」と同型の、見えないものが見えるネタ。コスト話は引用RTを誘発する。
- **対象**: CLI勢
- **検証メモ**: 最新バージョンの出力形式とサブスク（定額）ユーザー時の表示の意味を確認して注記。

#### 14. AIとの過去の会話は全部ローカルに残っている（全文検索する）
- **何ができる**: 「あのとき書いた神プロンプトどこだっけ」を解決。Claude Codeの全会話は `~/.claude/projects/` にJSONで保存されており、キーワード検索できる。
- **やり方**: `rg "キーワード" ~/.claude/projects`（Windowsは `Select-String`）で横断検索。よく使うプロンプトはそこから発掘してスキル化する、という導線につなげる。
- **ウケる理由**: 「実は全部残ってる」という発見系の裏技。自分の資産に気づかせる話は保存される。
- **対象**: CLI勢
- **検証メモ**: 保存パスとファイル形式の現行仕様、履歴の保持期間設定を確認。

### 法則E: 使い方の型（コピペ配布）

#### 15. 提案する前に「AI役員会」で炎上させておく
- **何ができる**: 慎重派CFO・攻めの事業責任者・現場代表の3役をAIに演じさせ、資料や企画を会議形式で叩かせる。本番の役員会で出る反論を先に潰せる。
- **やり方**: コピペ勢は3役ペルソナのプロンプト1枚で。Claude Codeなら `.claude/agents/` に3ペルソナを置き、並列レビューさせる（サブエージェント可視化ネタの実務応用編として出せる）。
- **ウケる理由**: 「サブエージェント」を技術ネタから業務ネタに翻訳する位置づけ。命名（AI役員会）だけで拡散する可能性がある。
- **対象**: 両方
- **検証メモ**: 3役の指摘が同質化しないようペルソナ定義を作り込み、実案件で1回試してから配布。
