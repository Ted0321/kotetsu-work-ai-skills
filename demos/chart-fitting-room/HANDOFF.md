## 1. 基本方針

### (a) 配布するのは「応用版」プロンプト

配布物は [`PROMPT.md`](./PROMPT.md) の **「応用版 — データの形を診断してから選ばせる」** 一本に決定。
精密版・短縮版も同ファイルに残っているが、**投稿で配るのは応用版**。

応用版の特徴は、10形式を固定で指示するのではなく、

1. 先に**データを診断**させる（時間軸はあるか／各列は加算できるか）
2. 20形式のメニューから**成立するものだけ**10個選ばせる
3. **落とした形式とその理由**を申告させる

こと。出力に診断欄と申告欄が付くぶん、精密版よりカチッとした成果物になる。

> 応用版は**単体で完結**している。精密版と併用せず、これだけを貼ればよい。
> 約4,200字。プレミアムの長文投稿なら1リプに全文が収まる。

### (b) デモ動画はゼロベースで作り直す

これまでの動画（営業利益データ、模造した外枠）は**すべて破棄**。作り直す。

| | 旧 | 新 |
|---|---|---|
| 見せるHTML | 営業利益・3年分（精密版の出力） | **部門別の組織データ（応用版の出力）** |
| 外枠 | 模造した再現UI | **実画面の録画** |
| 診断欄・申告欄 | なし | **あり**（これを映すのが目的） |

新しい動画で映すべきものは、**10枚のカードだけではない**。応用版の価値は
「AIが先に診断して、作れない形式を理由つきで落とす」ところにあるので、
**冒頭の診断欄と末尾の申告欄を必ず映す**。

## 3. 動画の仕様

- 尺 **45秒前後**
- 1600x900 以上。**H.264 / yuv420p / +faststart** で書き出し（X向け）
- **2テイクを繋ぐ**。実際のClaudeが10枚生成するのに数分かかるので、その待ちは動画に要らない

| テイク | 内容 | 尺 |
|---|---|---|
| 1 | 新規セッション → xlsx添付 → 指示をタイプ → 送信 → 思考が始まる | 約15秒 |
| 2 | プレビューで診断欄→10枚→申告欄をスクロール → 目的ボタン2回 | 約40秒 |

### テイク2で必ず映すもの

1. **冒頭の診断欄**（3〜4秒かけて）— 「時間軸: なし」「加算できるのは従業員数だけ」が読める速度
2. 10枚のカード（15〜18秒）— タイトルと説明文が読める速度
3. **末尾の申告欄**（2秒）— 落とした3形式と理由
4. 目的ボタンを**2回**押す — 「経営に人員の偏りを示す」→ 横棒、「人事に離職リスクを示す」→ 散布図

**ボタンは2回押す。** 1回だと「たまたま」に見えて、目的で答えが変わることが伝わらない。

### 撮り方

**全編を実写にするのが第一希望。** 手順は
[`recording/DESKTOP-CAPTURE-PROMPT.md`](./recording/DESKTOP-CAPTURE-PROMPT.md) に全部書いてある。
デスクトップアプリの computer use に渡す。

クラウド側のセッションは画面を持たないので実画面を録画できない。実写はデスクトップ側の担当。

**後退案**: computer use が安定しない場合、テイク1だけ実写で撮り、
テイク2は `recording/record.js` で生成して合成する。外枠は実写のまま。

> `recording/shell.html` は Claude Code の画面を模した**再現**であって実画面ではない。
> 実写が撮れるなら不要。

## 5. 検証済みで触らなくてよいもの

- **応用版プロンプトは実測検証済み**。まっさらなセッションに貼り、
  時系列なし・5列中4列が非加算・カテゴリ12という過酷なデータで一発生成させ、
  自己チェック8項目を通過。診断が正しく効いて時間軸を要する8形式を落とした
- **精密版も別途検証済み**（SaaSのARRで7項目通過）
- **配布前セルフチェック（2026-08-16）で7点を修正し、修正版をチャット条件
  （ブラウザ確認なし・一発書き切り・時系列データ）で追検証済み**。
  証跡は `verification-store-monthly.html` / `.csv`
- 検証で見つかった不足は**すべてプロンプトに反映済み**（計8点。パレートの2軸例外、
  カテゴリ10超は単色、非加算からの復元、凡例の重複、px指定とSVG伸縮の矛盾など）
- 撮影用HTMLは描画10枚・コンソールエラー0・ボタン動作を確認済み

**撮影の都合で必要な場合を除き、プロンプトとHTMLは触らないこと。**
