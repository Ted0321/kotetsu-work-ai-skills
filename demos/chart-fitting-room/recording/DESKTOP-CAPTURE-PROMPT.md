# デスクトップアプリに実画面を録画させる指示文

Claude Code **デスクトップアプリ**の computer use に渡す指示文。
クラウド側（このリポジトリで作業しているセッション）は画面を持たないので、実画面の収録はデスクトップ側の担当になる。

**狙い**: 外枠を模造せず、**全編を実写にする**。`demo-op-profit.html` は既にこのリポジトリにあるので、
プレビューを開くところまで実機でやれば、パネルの枠も中身も本物になり、合成が要らなくなる。

---

## 前提条件

| 条件 | 確認方法 |
|---|---|
| Pro または Max プラン | Max なら充足 |
| computer use が有効 | 設定から有効化（既定はオフ） |
| macOS の場合 | 「アクセシビリティ」と「画面収録」を許可 |
| デスクトップアプリが起動中 | computer use はアプリ起動が前提 |

> computer use は実際のデスクトップ上で動く。サンドボックスとは信頼境界が違うので、
> 走らせている間は挙動を見ておくこと。

---

## 事前にやっておくこと（人間の作業・2分）

1. **ブランチを取得**して `demo-op-profit.html` をローカルに置く
   ```
   git fetch origin claude/x-post-ai-tips-ideas-keuiyz
   git checkout claude/x-post-ai-tips-ideas-keuiyz
   ```
   ファイルは `demos/chart-fitting-room/demo-op-profit.html`

2. **xlsx をデスクトップなど拾いやすい場所に置く**
   `営業部門別_営業利益_2023-2025.xlsx`

3. **通知を切る**（Windows: 集中モード / macOS: おやすみモード）
   録画中にトーストが出ると使えなくなる

4. **見られたくないセッション名があれば整理**しておく（サイドバーが映る）

---

## 指示文（ここからコピペ）

```text
画面を操作して、デモ動画の素材を2本録画してください。
私は操作しません。すべて自動で進めてください。

## 何のための録画か

「1つのデータを10通りのチャートで描き分けて選ぶ」という機能の紹介動画を作ります。
Claude Code の実画面を使いたいので、あなたに操作と録画をお願いします。
編集と結合は別のセッションでやるので、あなたは素材を2本撮るところまでで構いません。

## 準備（録画を始める前に）

1. 画面録画に使えるツールを確認してください。
   - Windows: ffmpeg があれば `-f gdigrab` を使う。無ければ `winget install ffmpeg` を試す。
     どうしても入らない場合は Xbox Game Bar（Win+Alt+R でアクティブウィンドウの録画開始/停止、
     保存先は「ビデオ\キャプチャ」）を使う。
   - macOS: 標準の `screencapture -v` が使える。

2. Claude Code のウィンドウを、録画しやすいサイズに整えてください。
   - 目標は 1600x900 前後。難しければ最大化でも構いません。
   - どちらにしたか、最終的な解像度を最後に報告してください。

3. 録画対象は「Claude のウィンドウだけ」にしてください。
   デスクトップ全体を撮る場合は、他のウィンドウが映り込まないようにしてください。

4. 録画のフレームレートは 30fps、画質は高め（crf 18 相当）でお願いします。

## テイク1 — 指示を出してClaudeが動き出すまで（目安 15秒）

録画を開始してから、次の順で操作してください。各ステップの間は
「人が操作しているように見える」速度で、1〜2秒ずつ間を空けてください。

1. 1秒ほど何もせず静止（頭に余白を作る）
2. 新規セッションを作成する
3. `営業部門別_営業利益_2023-2025.xlsx` を入力欄にドラッグ＆ドロップして添付する
   （ドラッグが難しければ添付ボタンから選択でも可）
4. 入力欄に次の文をタイプする。一括貼り付けではなく、
   人が打っているように1文字ずつ打ってください。
   
   添付データを元に、全営業部門の営業利益を可視化するためのグラフを提案して

5. Enter で送信する
6. Claude が考え始めて、思考中の表示とツールの実行ログが出るところまで待つ
7. **8秒ほど経ったら録画を停止**する
   （このセッションは最後まで走らせなくて構いません。走っていても止めてOKです）

ファイル名は `take1-chat.mp4` にしてください。

## テイク2 — プレビューで10枚を見せる（目安 35秒）

テイク1とは別の録画です。ここが動画の本体になります。

1. 録画を開始する前に、`demos/chart-fitting-room/demo-op-profit.html` を
   **プレビューペインで開いた状態**にしておいてください。
   ペインは画面の右側4分の3程度を占めるようにしてください。
   開いたら、ページの一番上までスクロールを戻しておいてください。

2. 録画を開始する

3. 1秒静止

4. プレビューの中を**上から下までゆっくりスクロール**する。
   - 所要 15〜18秒かけてください。速いと読めません
   - カードのタイトルと、その下の説明文が読める速度が目安です
   - 一気に飛ばさず、なめらかに送ってください

5. 一番下まで行ったら、**2秒かけて一番上に戻る**

6. ページ上部にある「誰に、何を言いたいですか」のボタンのうち、
   **「役員に投資判断を迫る」をクリック**する
   - 押すと9枚が薄くなり、1枚だけが枠付きで残ります
   - 押した直後に出る説明文を**2秒ほど見せる**
   - そのあと、枠が付いたカード（バブルチャート）が画面に入るまでスクロールし、**2秒見せる**
   - 見せたら一番上に戻る

7. 同じ手順で、今度は**「現場に危機感を伝える」をクリック**する
   - 今度は別のカード（スロープグラフ）に枠が付きます
   - 同じく、説明文2秒 → そのカードまでスクロールして2秒

8. 1秒静止して録画を停止する

ファイル名は `take2-preview.mp4` にしてください。

## 終わったら報告してほしいこと

- 2本のファイルのフルパス
- それぞれの長さ（秒）と解像度
- ウィンドウを最大化したか、リサイズしたか
- 途中でうまくいかなかった操作があれば、その内容

## 守ってほしいこと

- 私のファイルを開いたり、他のアプリを操作したりしないでください。
  触るのは Claude Code のウィンドウと録画ツールだけです。
- 画面に他人の情報や機密が映り込みそうな場合は、録画を止めて私に知らせてください。
- うまく操作できないステップがあったら、無理に進めず、そこで止めて状況を報告してください。
  中途半端な素材より、どこで詰まったかが分かる方が助かります。
```

---

## 録画が上がったあと

2本をこのリポジトリで作業しているセッションに渡せば、次を行う。

1. テイク1の末尾とテイク2の先頭を繋ぐ（ジャンプカット）
2. 尺の調整（全体を40秒前後に収める）
3. 必要なら経過時間のオーバーレイを載せる
4. X 向けに H.264 / yuv420p / faststart で書き出し

**この方式なら合成箇所はゼロになる。** 全編が実画面の録画になるので、
「Claude じゃない感」は原理的に発生しない。

## うまくいかなかったときの後退案

computer use での操作が安定しない場合は、テイク1だけ人力で撮って渡す。
テイク2（プレビューのスクロールとボタン操作）は、クラウド側で
`recording/record.js` を使って生成し、テイク1の実写に合成する。
その場合、外枠は実写のまま、パネルだけが合成になる。
