## 動画で映るもの（文面はこれと噛み合わせる）

1. 冒頭の**診断欄** —「時間軸: なし」「加算できるのは従業員数だけ」
2. **10枚のカード** — 横棒 / ドットプロット / パレート / ツリーマップ / ヒストグラム /

3. 末尾の**落とした形式の申告** — ウォーターフォール・ファネル・ブレットを、理由つきで却下
4. **目的ボタンを2回**押して、推奨される1枚が入れ替わる

## 本投稿（案A・推奨）— 「診断する」が主役

応用版の一番の特徴を頭に置く。「10枚出る」だけなら他でもできるが、
**作れない形式を理由つきで落とす**のは他で見ない。

```text
「このデータ、どのグラフで見せるか」

10通り全部作らせて、実物を並べてから選ぶことにしました。

面白いのは、AIが先にデータを診断すること。

「時間軸がない」
「この列は足し算できない」

と判定して、成立しない形式は理由つきで落としてきます。

　ウォーターフォール
　→ 利益率は足し算できないため、増減の分解が定義できない

各カードには「この形式では"何が言えないか"」も書かせています。
弱点が書いてあるから、選べる。

プロンプトは下に置いておきます。
```

## 本投稿（案B）— 共感から入る

```text
「このデータ、どのグラフで見せるべきか」

迷った末に、結局いつも棒グラフになっていませんか。

10通り全部出させて、実物を並べて選ぶことにしました。
横棒・パレート・ツリーマップ・散布図・2×2・ヒートマップ…

しかもAIが先にデータを診断して、
このデータでは作れない形式は理由つきで落としてくれます。

各カードの「何が言えないか」まで書いてあるので、選べます。
```

## リプ1 — プロンプト

配布するのは [`PROMPT.md`](./PROMPT.md) の**応用版**（約4,200字）。
プレミアムの長文投稿なら1リプに全文が収まる。分ける場合は次のどちらか。

**(a) リプを分割して全文を載せる**
「ここまでやってるのか」という凄みは出るが、長さで離脱するリスクがある。
分けるなら 手順まで / 品質ルール / 自己チェック の3本が切りやすい。

**(b) 冒頭だけ載せてGitHubへ誘導**
```text
プロンプト全文はこちら（長いのでGitHubに置いてあります）

やっていることは3つだけです。

1. データを診断させる（時間軸はあるか、各列は足し算できるか）
2. 20形式のメニューから、成立するものだけ10個選ばせる
3. 落とした形式は理由を書かせる

（GitHubリンク）
```

## リプ2 — 補足と証跡

```text
売上データ以外でも動きます。

動画で使っているのは、時系列がない12部門の組織データ。
売上・利益のような「足せる数字」が1本しかないので、
積み上げ棒もウォーターフォールも成立しません。

それをAIが自分で判定して、
パレート・ツリーマップ・散布図・レンジプロットに寄せてきます。
```

## 撮影メモ

動画の撮り方は [`recording/DESKTOP-CAPTURE-PROMPT.md`](./recording/DESKTOP-CAPTURE-PROMPT.md) に集約。
文面と噛み合わせるうえで外せないのは次の3点。

- **診断欄を必ず映す**（案A・案Bのフックがここに依存している）
- **落とした形式の申告を必ず映す**（「ウォーターフォール → 利益率は足し算できない」の実物）
- **目的ボタンは2回押す**（1回だと「たまたま」に見える）
