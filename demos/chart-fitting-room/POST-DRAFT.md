# A-4 チャート試着室 — X投稿ドラフト

構成: 本投稿（フック＋動画）→ リプ1（コピペ用プロンプト）→ リプ2（精密版の配布）→ リプ3（別データでの証跡）

プロンプトを本投稿に入れず、リプに分けている理由は2つ。本投稿を短く保って離脱を防ぐことと、
プロンプト目当てのリプ展開がエンゲージメントとして効くこと。

---

## 本投稿（案A・推奨）— 「同じデータ」で驚かせる

デモが持っている一番の驚きを頭に置く。動画の1枚目と噛み合う。

```text
同じ売上データです。

上は「全社+5%、順調に成長」。
下は「主力が崩壊寸前」。

どちらも数字は正しい。
グラフの選び方だけで、結論は逆になります。

だから10通り全部作らせて、
実物を見ながら選ぶことにしました。

「誰に何を言いたいか」を選ぶと、
AIが1枚に絞って理由まで書いてくれます。

プロンプトは下に置いておきます。
```

## 本投稿（案B）— あるあるペインから入る

案Aが刺さらなかったときの差し替え用。共感の入口は広いが、驚きは弱い。

```text
「このデータ、どのグラフで見せるべきか」

迷った末に、結局いつも棒グラフになっていませんか。

10通り全部作らせて、実物を並べて選べるようにしました。
折れ線・滝・バブル・2×2・ヒートマップ・スロープ…

しかも各チャートに
「この形式では"何が言えないか"」まで書かせています。

ここが効きます。弱点が書いてあるから、選べる。
```

## 本投稿（案C）— 短尺・数字で入る

動画のインパクトに全部預ける場合。テキストは最小限。

```text
グラフ選びで迷う人へ。

全部作らせて、選べばいい。
```

## リプ1 — コピペ用プロンプト

```text
コピペ用（データを末尾に貼るだけ）

このデータで、考えられるチャート形式を10通り作って、1枚のHTMLに並べて。
折れ線 / 積み上げ棒 / 100%積み上げ / ウォーターフォール / バブル /
2×2マトリクス / ヒートマップ / 横棒ランキング / スロープグラフ / 小倍数。

各チャートには「何が言えて、何が言えないか」を1文つけて。
色は形式ごとではなくカテゴリごとに固定（製品Aは10枚とも同じ色）。
ライブラリは使わずSVGで、ダークモードにも対応して。

そのうえで上部に「誰に、何を言いたいか」を選ぶボタンを4つ置いて。
押したら推奨の1枚以外を薄くして、なぜその1枚なのかを数字つきで説明して。

［ここにデータを貼る］
```

## リプ3 — 別データでの証跡（任意）

信頼を足す1手。検証で作ったSaaS版のスクショを貼る。

```text
売上構成以外でも動きます。
```

## 撮影メモ（動画 30〜40秒）

本投稿の文面と噛み合わせる。案Aで撮る場合の割り。

| 秒 | 画 | ねらい |
|---|---|---|
| 0–4 | 折れ線（全社は右肩上がりに見える）をアップ | 「順調」の印象を作る |
| 4–8 | スロープグラフへ切り替え（主力が急降下） | **同じデータで印象が反転**する瞬間 |
| 8–16 | 引いて10枚のグリッド全体を見せる | 画面が埋まる。足を止めさせる |
| 16–24 | 「役員に投資判断を迫る」をクリック → 9枚沈み1枚光る | 機能の説明 |
| 24–32 | 「現場に危機感を伝える」に切替 → **別の1枚**が光る | いちばんの見どころ |
| 32–40 | PowerPointが開く（第2幕を出す場合） | 実務で使える証明 |

- 0–8秒で「同じデータなのに逆に見える」を成立させるのが最優先。ここで離脱が決まる
- 目的の切替は2回見せる。1回だと「たまたま」に見える
- 経過時間のオーバーレイを入れるなら「この10枚、指示1回」と出す

## 出す順番についてのメモ

- A-4は**シリーズA（コンサル図解をAIで）の初回**に置くのが良い。ここで「10形式ある」と
  見せておくと、以降「今日はバブルの作り方」「今日は滝グラフ」と各論を連打する土台になる
- PowerPoint化（第2幕）は、A-4がバズった後の続編に温存する手もある。
  1投稿に情報を詰めすぎると、動画の見どころが割れる
