# A-4 チャート試着室 — X投稿ドラフト

**この投稿は第1幕まで。** PowerPoint化は続編に温存する（末尾のメモ参照）。

動画で伝えるのは2つだけ。**10枚のカードが出てくること**と、**その中から自分で選べばいいこと**。
目的セレクタ（AIが1枚に絞る機能）は動画に映さないので、本文でも主役にしない。リプで触れる。

構成: 本投稿（フック＋動画）→ リプ1（コピペ用プロンプト）→ リプ2（精密版の配布）→ リプ3（別データでの証跡）

プロンプトを本投稿に入れず、リプに分けている理由は2つ。本投稿を短く保って離脱を防ぐことと、
プロンプト目当てのリプ展開がエンゲージメントとして効くこと。

---

## 撮影メモ（動画 約30秒）

いつもの型。デスクトップアプリで指示 → サイドバーに成果物、の一本道。演出は足さない。

| 秒 | 画 |
|---|---|
| 0–6 | Claude Codeのデスクトップアプリ。**ブランクの状態**から指示を打ち込む |
| 6–9 | 実行開始。処理が走り出す |
| 9–12 | 画面の**右4分の3にサイドバー**が開く |
| 12–30 | サイドバーの中の**10枚のカードを、上からゆっくりスクロール** |

打ち込む指示（画面で読める速度で）:

```text
添付のIR資料の営業利益の分析結果を報告したいので、
バブルチャートなどを使って整理してください
```

撮り方のメモ:

- スクロールは**ゆっくり**。カードのタイトルと「何が言えないか」の一文が読める速度にする。
  ここが保存される理由なので、速く流すと価値が消える
- カードが1枚ずつ光る／沈むような演出は入れない。**10枚が並んでいる事実**だけで足りる
- 入力は整形済みCSVではなく**資料の添付**にする。「手元の資料をそのまま渡せる」が伝わる
- 目的セレクタは映さない。動画が長くなるうえ、「自分で選べばいい」というメッセージとぶつかる

## 本投稿（案A・推奨）

動画が見せるもの（10枚出る／自分で選ぶ）と噛み合わせた文面。

```text
「このデータ、どのグラフで見せるか」

同じ数字でも、選ぶ形式で結論は変わります。
折れ線なら「順調」、スロープなら「主力が崩壊寸前」。

なので、迷うのをやめました。
考えられる形式を10通り全部出させて、
実物を並べてから選ぶ。

折れ線・積み上げ棒・100%積み上げ・ウォーターフォール・
バブル・2×2・ヒートマップ・横棒・スロープ・小倍数。

各カードには
「この形式では"何が言えないか"」も書かせています。
弱点が書いてあるから、選べる。

プロンプトは下に置いておきます。
```

## 本投稿（案B）— 共感から入る

```text
「このデータ、どのグラフで見せるべきか」

迷った末に、結局いつも棒グラフになっていませんか。

10通り全部出させて、実物を並べて選ぶことにしました。
折れ線・滝・バブル・2×2・ヒートマップ・スロープ…

しかも各カードに
「この形式では"何が言えないか"」まで書かせています。

ここが効きます。弱点が書いてあるから、選べる。
```

## 本投稿（案C）— 短尺

```text
全部出させて、選べばいい。
```

## リプ1 — コピペ用プロンプト

```text
コピペ用（データを末尾に貼るだけ）

このデータで、考えられるチャート形式を10通り作って、1枚のHTMLに並べて。
折れ線 / 積み上げ棒 / 100%積み上げ / ウォーターフォール / バブル /
2×2マトリクス / ヒートマップ / 横棒ランキング / スロープグラフ / 小倍数。

各チャートには「何が言えて、何が言えないか」を1文つけて。
色は形式ごとではなくカテゴリごとに固定（製品Aは10枚とも同じ色）。
ライブラリは使わずSVGで、ダークモードにも対応して。

［ここにデータを貼る］
```

> 短縮版から目的セレクタの指定を外している。動画で見せない機能を
> プロンプトに残すと、出てきたものと動画が食い違うため。
> セレクタが欲しい人向けの一文はリプ2で足す。

```text

・ラベルが重なって読めない

・ダークモードで文字が消える

これを全部潰した精密版はこちら。
「誰に何を言いたいか」を選ぶと1枚に絞ってくれる版も入れてあります。

（GitHubリンク）
```

> リンク先には第2幕（PowerPoint化）のプロンプトも置いてあるが、投稿本文では触れない。
> 見つけた人にとっての「おまけ」に留め、続編の驚きを削らないため。

## 出す順番についてのメモ

- A-4は**シリーズA（コンサル図解をAIで）の初回**に置く。ここで「10形式ある」と
  見せておくと、以降「今日はバブルの作り方」「今日は滝グラフ」と各論を連打する土台になる
- **第2幕（PowerPoint化）は続編として温存**。切り口は「試着室で選んだ1枚を、
  そのままPowerPointにする」。画像貼り付けではなくネイティブチャートなので、
  開いた人が数値を編集できる — ここが単独でもフックになる
- 第2幕の素材は実装・検証とも済んでいる（`to-pptx.js` と `PROMPT.md` の第2段階）ので、
  撮影だけで出せる状態
- **目的セレクタも、実は続編1本ぶんの素材**。「AIにどれを使うべきか選ばせる」は
  今回の「自分で選ぶ」と対になる話なので、別投稿にした方が両方立つ
